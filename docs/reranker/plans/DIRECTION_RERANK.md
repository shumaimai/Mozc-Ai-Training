# 現在の方針 — 文脈リランカー（実使用ログ収集フェーズ）

更新: 2026-08-15  
関連: `docs/reranker/plans/DECISION_RERANK.md`（判断）/ `docs/reranker/tasks/NEXT_TASK_USAGE_GUARD.md`（ガード）/ `docs/reranker/reports/PHASE3_CTX_REPORT.md`（詳細）

---

## 一言でいまどこにいるか

30m 文脈リランカーは **Wikipedia では効く（CS Δ +24〜49pt）が、実タイピングではガードなしだと Mozc より −8pt**。
ガードで止血して net +0.5pt・傷害0 まで戻したが、それは**180/186 件でモデルを呼ばなくなった＝ほぼ Mozc に戻した**結果。
→ **今の実使用価値はほぼゼロ。本当の価値を出すには「実分布で再学習」が要る。その前に実データを貯める段階。**

## 選んだ道：A → C（データを積んでから再学習）

1. **既定 OFF のまま**、ガード＋デーモンは常駐させて使い続ける。
2. **実使用ログ（`ime_usage_pairs.jsonl`）を貯める**。← いまここ
3. 定期的に**ログを集計して傾向を確認**（下記チェックリスト）。
4. 十分貯まったら **再学習（C）**：実分布のアンカー＋失敗モード修正＋実ログで評価。
5. **go/no-go 門**を超えたら実機 ON を検討。超えなければ棚上げ（D）。

**やらないこと**（制約）: 既定 ON・70m への戻し・int8・文脈短縮・ガードの186件向けさらなる穴埋め。

---

## 使っている間にやること

- デーモンを常駐（`scripts/_start_rerank_daemon.sh`、intra=12）。
- `MOZC_RERANK_ENABLED=1` は**任意**（ONで使うと実験になるが、たまに変な変換が出たら OFF に戻してよい）。既定は OFF。
- ログが `artifacts/rerank_ctx/eval/ime_usage_pairs.jsonl` に貯まる。**消さない・別セッション分も追記**。
- 変な変換に気づいたら、その読み・文脈をメモしておくと再学習で効く。

## データの目標

- **量**: 1〜2千件以上（今は186）。
- **多様性**: 1セッション/1人に偏らないよう、日をまたいで色々な文章を打つ。
- これが再学習の**アンカー源**であり**主評価**になる。

---

## 定期チェックリスト（ログをまとめる時に出す数字）

`ime_usage_pairs.jsonl` から毎回これを出す（`usage_replay_report.json` 相当）:

1. **件数**（累計・今回分）
2. **net vs Mozc**: `shown==wanted` 率 −　`mozc_top1==wanted` 率
   - ガードあり／なし両方
3. **上書き回数**と **助けた / 壊した** 件数
4. **ガード発動率**（何%がモデルを呼ばずスキップされたか）
5. **壊した例の一覧**（文脈・読み・出た・欲しい・margin）← 失敗モードの観察
6. **助けた例の一覧** ← 本当に価値が出ている同音異義

見るポイント:
- 壊した件が増えていないか（ガードの穴）。
- 助けた件が「記者/汽車」以外にどれだけ出るか（＝実使用でのリランクの実力）。
- 新しい失敗パターン（新しい珍字・文脈型）が出ていないか。

---

## 再学習（C）に進む条件と中身

**進む合図**: ログが1〜2千件貯まり、かつ「助けたい同音異義」が実使用で繰り返し観測される。

**再学習の中身**（`docs/reranker/tasks/NEXT_TASK_USAGE_GUARD.md` Task3）:
- ありふれた語・短い読み・数字文脈を **「上書きするな」アンカー**として大量投入。
- 旧字体・珍字の昇格に**ペナルティ**。
- **評価に実ログを含める**（Wikipedia だけで判断しない）。
- 30m・τ 再スイープ。

**go/no-go 門（出荷ONの条件）**:
> より大きい実ログ評価で、**net が Mozc を実質マージンで上回る（目安 ≥ +3〜5pt）**、かつ傷害が増えない。
> 超えられなければ正直に**棚上げ（D）**。「Wikipedia で効く」だけでは ON にしない。

## いまの出荷構成（参考・凍結中）

| 項目 | 値 |
|--|--|
| モデル | `track30m_ctx`（modernbert-ja-30m）、ONNX fp32 |
| τ / max_len / cand_cap | 2.5 / 128 / 30 |
| 文脈 | `clean_context` 末尾50字（短縮しない） |
| 配信 | WSL 常駐デーモン `127.0.0.1:17890`、intra=12、フェイルセーフ200ms→Mozc順 |
| ガード | ホワイトリスト488語＋短読み/空文脈/珍字スキップ（3経路同一） |
| 既定 | **OFF** |
| 速度 | 30m デーモン e2e p50 57ms / p95 132ms（quiet） |

70m（`trackB_v2_continue`）は Volume に保持、戻す予定なし。

## 一文

**既定OFFのまま使い続けて実ログを貯める → 定期集計で傾向を見る → 十分貯まったら実分布で再学習 → go/no-go門を超えたらON、ダメなら棚上げ。** いまは「データを厚くする」段階。
